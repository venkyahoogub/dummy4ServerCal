This Debian package contains the ALP library with examples and targets the x86_64 (amd64) platform.

It has been tested on Ubuntu 22.04 and 24.04 and requires the libusb-1.0-0 package. To compile the samples, the cmake and g++ packages are also required.

This is beta software and may contain bugs and performance limitations.

Installation

A .deb package for Ubuntu, libalp43_0.0.2-beta_amd64.deb is provided in the zip archive containing this file.

To install the package, run the following command from the directory containing the .deb file:

sudo dpkg -i libalp43_0.0.2-beta_amd64.deb

If installation fails, run the following to install any missing dependencies.

sudo apt-get update
sudo apt-get --fix-broken install

Documentation

After installation, you can open README.html installed under /usr/share/doc/libalp43 for an overview and links to more documentation.
